# Documents

**One row per document, saying what it is *for*.** The index is the one page in
`docs/` that is not itself indexed; the front page is
[`../README.md`](../README.md) and nothing here competes with it.

| document | what it is for |
| --- | --- |
| [`ai-novelty.md`](ai-novelty.md) | **Where this ecosystem stands with respect to related work.** A register of one row per mechanism, the nearest outside work it is measured against, and the state of that comparison — seven rows answered after one reading pass, three still unsettled |
| [`recommendations.md`](recommendations.md) | **Hypothetical implications of the reading.** Five possibilities and one observation, with no practical requests or implementation priority; an entry belongs there only if a reading produced it |
| [`science-fiction.md`](science-fiction.md) | **The upper bound: the furthest this ecosystem allows itself to plan.** Seven scenarios, ordered nearest first, each ending in something that may not be done. Marked at the top as agent-written fiction that is not to be taken seriously |
| [`maintenance.md`](maintenance.md) | **How a person maintains this repository**, and what membership of the Eunoia ecosystem costs this tree. The entry point for whoever is doing the work |
| [`discussion.md`](discussion.md) | **The channel to the other tools in the ecosystem**, and not a document: live topics only, gated at the top, each one removed when its discussion ends |

**None of the three written documents is finished**, and none is a result.
`ai-novelty.md` has had one reading pass and names the two jobs that come next:
**read the three rows still unsettled**, and **move the six rows already found
ordinary out of the file**, which the page's own relocation rule requires and
the pass did not do. **`recommendations.md` is downstream of both** — an entry
there is only as good as the reading under it.

**`discussion.md` is the one row here that is not a document.** Presence in it
is the status, so it holds whatever is unsettled between this repository and
another today, and a topic leaves it when the discussion ends rather than when
somebody tidies.
